Ajustes

Borrado automático de tachados

Cuánto tiempo pasa desde que tachas un producto hasta que desaparece del ticket. Los productos fijos ⭐ nunca se borran: pasado ese tiempo se destachan solos para la próxima compra.

Sincronización con GitHub

Los tickets se guardan en tickets.json dentro de tu repositorio (rama datos). Así todos tus dispositivos ven lo mismo.

Crea un token fine-grained en github.com/settings/personal-access-tokens/new con acceso solo a este repositorio y permisos Contents: Read and write y Actions: Read and write (este último solo para actualizar el catálogo desde la app).
